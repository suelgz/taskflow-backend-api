# Postman ekran görüntüleri (teslim)

1. Terminalde `npm install` ve `npm start` çalıştırın.
2. `TaskFlow.postman_collection.json` dosyasını Postman'e import edin.
3. 01-05 isteklerini sırasıyla gönderin. HTTP durum kodu ve response body'si görünür olsun.
4. `postman/screenshots/` klasörüne şu **gerçek Postman** ekran görüntülerini ekleyin:

- `01-create.png` — POST /tasks → 201
- `02-list.png` — GET /tasks → 200
- `03-detail.png` — GET /tasks/:id → 200
- `04-update.png` — PUT /tasks/:id → 200
- `05-delete.png` — DELETE /tasks/:id → 200

Ekran görüntüleri henüz alınmamıştır, sahte görseller kullanılmamıştır.
